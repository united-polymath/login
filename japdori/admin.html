📌 토픽(스레드) 분리 — 선택

관리자 그룹에 포럼 모드(Topics)를 켜셨다면 알림 종류별로 토픽을 나눠 받을 수 있어요.
비워두면 그룹 메인 채팅으로 전송됩니다.

📌 셋업 가이드
1. @BotFather 에서 /newbot → 봇 만들고 토큰 받기
2. 관리자 + 봇을 한 텔레그램 그룹에 초대 (봇은 관리자 권한 부여 필수)
3. chat ID 알아내기: 그룹에서 메시지 보내고 메시지 우클릭 → "메시지 링크 복사" → 링크 t.me/c/숫자/...의 그 숫자 앞에 -100을 붙이기 (예: 3906319092 → -1003906319092)
4. 토픽 thread ID: 각 토픽에서 메시지 → 링크 복사 → t.me/c/그룹/토픽ID/메시지ID의 가운데 숫자
5. 입력 → [저장] → [테스트 전송]
