흰 배경 · 올리브 포인트(#C5F23F) · 검정 텍스트의 클린 챌린지 웹앱.
참가비 ₩30,000을 2주(14일) 챌린지에 걸고, 매일 일정액(약 ₩2,143)이 미션 결과에 따라 보존/손실되는 구조.

## 햄스터 이미지 넣기

`assets/images/` 폴더에:
- `hamster-1.png`

자동 감지되어 홈 화면 확언 카드 오른쪽 박스에서 **15초마다 fade 전환**됩니다. 이미지가 없으면 이모지(🤑 😈 💸 🐹 🪙)로 대체.

## 챌린지 정책

- **참가비**: ₩30,000
- **기간**: 14일
- **일당 보증액**: ₩2,143 (= 30,000 ÷ 14)
- 미션 성공(승인) → 그 날의 ₩2,143 **보존** (환급 풀에 적립)
- 미션 실패 → 그 날의 ₩2,143 **손실**
- 마이페이지 보증금 카드에 일자별 ledger가 보여지고, 14일분이 시각적으로 누적됨

## 환급 기준 (마이페이지에서 표시)

| 이행률 | 환급 | 선물 |
|---|---|---|
| 100% | ₩30,000 전액 | 특별선물 |
| 90% 이상 | ₩27,000 | 응원선물 |
| 70% 이상 | ₩21,000 | 소정선물 |
| 50% 이상 | ₩15,000 | — |
| 미만 | 환불 없음 | — |

## 인증 흐름

1. 회원이 홈 화면 트래커의 **오늘 칸** 클릭 OR 하단 ＋ 버튼 → 사진 선택
2. 미리보기 모달 → "제출" 누름
3. 해당 날짜 상태가 `pending_review`로 변경 (트래커에 ⏳ 노랑 점선 표시)
4. **관리자 텔레그램으로 알림 즉시 전송**
5. 관리자 패널 → **인증 검토** 탭에서 사진 + 미션 + 사용자 정보 확인
6. 승인 → `approved` (트래커 올리브) / 거절 → `failed` (트래커 빨강)
7. 회원 마이페이지 보증금 ledger와 트래커 자동 업데이트

## 날짜 클릭 시 디테일 모달

홈/마이페이지의 트래커 셀 또는 보증금 ledger 행을 누르면 그 날의:
- 미션 텍스트
- 상태 뱃지
- 업로드된 사진 (있다면 풀 사이즈)
- 제출/검토 시각
- 관리자 코멘트
- 액션 버튼 (오늘/검토중일 때 다시 올리기)

## 회원가입 / 승인

1. `signup.html` → 신청 (`status: pending`)
2. **관리자 계정**은 `assets/app.js` 의 `SEED.ADMIN_EMAIL` / `SEED.ADMIN_PASSWORD` 로 자동 시드됨
3. 기존에 시드되어 있던 관리자가 있어도 SEED 값이 바뀌면 자동으로 이관됨 (이메일/비번 동기화)
4. `admin.html` → 회원 관리 → **승인** 클릭
5. → 회원 로그인 가능

## 텔레그램 알림 (관리자 3명에게 한꺼번에)

### 권장: 텔레그램 그룹 채팅
1. [@BotFather](https://t.me/botfather)에서 `/newbot` → 봇 만들고 토큰 받기
2. "잡도리 운영방" 같은 그룹 생성 → 관리자 3명 + 봇 초대
3. 그룹에서 메시지 한 번 보낸 뒤 `https://api.telegram.org/bot<TOKEN>/getUpdates` 호출 → `chat.id` 확인 (음수)
4. 관리자 패널 → **텔레그램 알림** 탭에서:
   - 봇 토큰
   - 관리자 그룹 chat_id (-1001234567890 같은 음수)
   - 공개 채널 ID (`@channel_name`, 선택)
   - 활성화 토글 ON → 저장
5. **테스트 전송** 버튼으로 동작 확인

→ 봇이 그룹에 메시지를 보내면 그룹에 속한 모든 관리자(3명)에게 알림이 갑니다.

### 자동 발송되는 알림

| 이벤트 | 대상 | 메시지 예시 |
|---|---|---|
| 새 가입 신청 | 관리자 | `🆕 새 가입 신청 — 지수 · jisoo@email.com` |
| 인증 사진 제출 | 관리자 | `📷 새 인증 도착 (검토 필요) — 지수 · DAY 04` |
| 인증 사진 제출 | 공개 | `🔥 지수 님이 DAY 04 미션을 인증했습니다!` |
| 승인/거절 | 공개 | `✅ 지수 님 DAY 04 인증 승인!` |
| 문의 도착 | 관리자 | `📩 문의 도착 — [지수] 제목 ...` |

### 그룹 만들기 어려울 때 (대안)
관리자 채팅 ID 입력란에 개인 ID를 **쉼표로 구분**해서 여러 개 입력 가능:
```
123456789,987654321,555555555
```

## 보안 안내 (실서비스 전환 시)

현재는 프로토타입이라 클라이언트 JS에서 텔레그램 봇 토큰을 들고 있어요. 누구나 페이지 소스를 열면 토큰을 볼 수 있고 봇을 탈취할 수 있습니다. 실서비스 시에는:
- 봇 토큰을 **서버에만** 두고
- Vercel/Netlify/Cloudflare Workers의 서버리스 함수를 만들어 거기서만 텔레그램 API를 호출
- 클라이언트는 함수 엔드포인트만 호출

## localStorage 키

| 키 | 내용 |
|---|---|
| `japdori.users` | 사용자 목록 |
| `japdori.session` | 현재 세션 |
| `japdori.notices` | 공지사항 |
| `japdori.affirmation` | 확언 텍스트 |
| `japdori.avatar` | 아바타 (dataURL) |
| `japdori.telegram` | 텔레그램 설정 |
| `japdori.attendance.<userId>` | 사용자별 14일 출석/인증 데이터 |

데이터 초기화는 마이페이지 → "챌린지 데이터 초기화" 또는 콘솔에서 `localStorage.clear()`.
